Download the corpus

The rules this planner runs on are not locked inside the app. The whole graded set — 113 rules, each with the mechanism it works by, the strength of its evidence, whether a human has checked its sources, and those sources — is one file you can download, read, and keep.

Download the corpus one JSON file · CC BY-SA 4.0

What is in it

One entry per rule, in machine-readable form: the claim, the named mechanism, the evidence grade, whether the sources have been verified by a person, the sources themselves, and — when the file is built from a full clone of the history — the dated record of every change that rule has been through. A stable identifier on each rule lets you cite one and find it again. The file names the exact commit it was built from, so two people who download it can tell whether they are looking at the same corpus.

What the grades mean

Every rule carries one of five grades, from “well established” down to “refuted”, and the file spells each grade out in those words rather than leaving you a bare letter. A grade is never given to a rule that cannot state its mechanism in one sentence; a claim that only correlates is downgraded or dropped rather than dressed up. The refuted tier — 1 folk claims this corpus checked and rejected — is in the file too, because a correction is worth as much as a rule.

Verified and unverified are marked, always

112 of the 113 rules are marked verified: a person read a real source, named in the file, and confirmed the claim. Anything a language model asserted but no human has yet checked is marked unverified and never presented as fact — and the model is never allowed to promote its own work. That single line is the difference between this and a dataset that cites papers nobody opened.

The licence

The corpus is offered under Creative Commons Attribution-ShareAlike 4.0. Use it, build on it, ship it — but credit it, and pass on the same freedom. Share-alike is deliberate: a mechanism-graded rules file should not be quietly absorbed into a planner whose business depends on not admitting its companion charts are folklore.
